# 分类自定义管理

## 工作流程

1. 数据库设计：categories 表（id、parent_id、name、sort、is_preset），预置分类 is_preset=1 只读。
2. 数据访问层：实现 list/add/update/delete，校验规则：
   - 预置分类禁止修改与删除
   - 同级重名（不区分大小写）拒绝
   - 被记录使用的分类禁止删除；删除一级分类时级联检查子分类
3. 界面层：分类管理页区分预置（🔒）与自定义；自定义可改名/删除；可在一级下添加二级分类。
4. 录入界面：分类下拉按树形展示（一级分组 + 二级选项），包含预置与自定义。
5. 验证：增删改查、重名、使用中删除拦截、重启后数据保持。

## 注意事项

- 预置分类写保护必须在数据层强制校验，不能只依赖界面。
- 删除操作需保证无孤儿数据，使用事务。
