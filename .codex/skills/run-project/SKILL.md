# 运行项目

## 工作流程

1. 检查依赖：确认 node_modules 是否存在；不存在则执行 npm install。
2. 检查前端构建产物：dist/ 不存在或过旧时执行 npm run build。
3. 启动应用：
   - 快速运行：npm start（加载已构建界面）
   - 开发模式（改代码热更新）：npm run dev
4. 等待窗口出现，确认进程正常（窗口标题应为“鲲鹏记账”），用中文向用户反馈启动结果。
5. 若启动失败，查看报错并修复（常见：原生模块 better-sqlite3 未重建，执行 npm run rebuild）。

## 注意事项

- 启动前先检查是否已有实例在运行，避免重复窗口。
- 全程使用中文反馈，操作前简述意图。
