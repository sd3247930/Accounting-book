# 2048 小游戏（含 AI 自动玩功能）—— 产品设计文档

> **项目名称**：2048 小游戏（AI 增强版）
> **文档版本**：v2.0
> **创建日期**：2026-08-15
> **文档状态**：已确认（技术方案：方案 A = HTML + CSS + JS + Electron，集成进鲲鹏记账 App）

---

## 一、需求背景

为鲲鹏记账桌面应用内置一款 **2048 小游戏**，既可供用户手动休闲娱乐，也能展示 **AI 自动玩** 功能，让用户观察 AI 如何通过策略不断合成高分。游戏离线可用、启动迅速，并内置 AI 自我测试能力，以验证 AI 至少能达到 1024 分以上。

## 二、核心目标

1. **完整的 2048 游戏交互**：支持键盘方向键（↑↓←→）控制方块移动，实时计分，游戏结束判定，重新开始，最高分本地持久化。
2. **AI 自动玩功能**：
   - 提供“AI 自动玩”按钮，点击后 AI 自动执行一系列移动操作，直至游戏结束或达到指定分数。
   - AI 算法基于启发式评估（空格数、最大方块位置、单调性等），无需外部库。
   - AI 运行过程中界面实时更新，用户可随时暂停/继续或停止。
3. **AI 自我测试能力**：
   - 提供“AI 自我测试”按钮，自动运行多局游戏（如 10 局），统计达到 1024 分及以上的局数，并报告成功率。
   - 测试结果在界面上显示，确保 AI 至少能在一局中达到 1024 分（验收基准）。
4. **集成进鲲鹏记账**：在侧边栏增加“2048”入口，复用现有 Electron + Vue 3 + Element Plus 框架与界面风格。
5. **代码质量**：所有源代码模块化，添加完整中文注释。

## 三、技术方案（已确认：方案 A）

- **游戏核心**：HTML5 + CSS3 + 原生 JavaScript（ES6+）
- **桌面框架**：复用项目现有 Electron（37.x）+ Vue 3 + Vite
- **AI 算法**：纯 JavaScript 启发式搜索（评估函数 + 有限深度期望搜索），不使用任何第三方 AI 库
- **最高分存储**：localStorage（本地持久化）

## 五、AI 算法设计

AI 采用简化启发式搜索策略，不依赖深度学习：

- **评估每个可能移动方向（上下左右）后的局面得分**，得分由多个因子加权：
  - 空格数量（越多越好）
  - 最大方块是否在角落（鼓励最大块靠边）
  - 相邻方块数值差异（差异越小越好，表示有序）
  - 单调性（行/列数值呈单调递增或递减）
- AI 选择得分最高的方向执行，并重复此过程直至游戏结束。
- 为稳定突破 1024 分，决策时做**有限深度期望搜索**：模拟移动后对所有可能生成的新块（2/4）位置按概率求期望得分。

## 六、约束条件

1. 不得使用任何第三方 AI 库或框架，所有算法均用纯 JavaScript 实现。
2. 必须适配 Windows 10/11 和 macOS 14+。
3. AI 自动玩和自测功能不能影响手动游戏体验，两者互不干扰。
4. 所有操作均本地执行，无网络请求。

## 七、验收标准

1. **手动游戏**：键盘控制响应灵敏，方块合并逻辑正确，计分准确，游戏结束判定无误，最高分持久化。
2. **AI 自动玩**：点击“AI 自动玩”按钮后 AI 开始执行移动，界面实时刷新；可随时暂停/继续/停止；结束后显示最终得分。
3. **AI 自我测试**：自动运行 10 局游戏，显示统计结果（达标局数、最高分），至少 1 局得分超过 1024。
4. **集成**：侧边栏出现“2048”入口，游戏界面与记账 App 整体风格一致。
